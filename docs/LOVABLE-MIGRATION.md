# Lovable migratie

Deze repository is bedoeld als onafhankelijke vervanger van de Lovable-hosting.

De frontend is bewust dependency-vrij gemaakt:
- geen Lovable runtime;
- geen React-build nodig;
- geen Lovable credits;
- rechtstreeks te hosten via GitHub Pages.

De bestaande Lovable-app kan tijdelijk blijven bestaan als fallback totdat de GitHub Pages-versie is getest.
